# Security Policy

## Supported Versions
We actively maintain the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | ✅                 |
| 1.x     | ✅ (critical fixes only) |
| < 1.0   | ❌                 |

## Reporting a Vulnerability
We take security issues seriously. If you discover a vulnerability:

1. **Do not open a public issue.**
2. Contact our security team at security@example.com.
3. Provide:
   - A detailed description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested mitigations

We will acknowledge receipt within **48 hours**.

## Response Timeline
- **Critical (CVSS ≥ 9.0):** Fix or mitigation within **7 days**.
- **High (CVSS 7.0–8.9):** Fix within **14 days**.
- **Medium (CVSS 4.0–6.9):** Fix within **30 days**.
- **Low (CVSS < 4.0):** Addressed in the next scheduled release.

## Disclosure Policy
- We follow a **responsible disclosure** process.
- Please allow us time to investigate and release a fix before public disclosure.
- We will credit reporters in release notes unless anonymity is requested.
